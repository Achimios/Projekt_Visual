# 草稿方案 ——《Can't Kill Us》怎么从一首歌做到一部片

> 2026-10-20 起草（Eidolon 会话），给 Leo 和 Zaoeyo 看。白话版，不是规格。
> 工具怎么调 → `4_Eidolon/-给人类的解释/生成工具怎么用.md`；每个脚本是什么 → 同目录 `工具一览.md`。
> 【没验到】= 还没真跑过。

## 一句话

**先定这部片想说什么（Thymos），再听歌，再按段排情绪，再用文字剪辑表定节奏，然后每个镜头挑最合适的工具出画面，最后交给 Zaoeyo 美化。**
原版 MV 一开始只是占位的脚手架，最后会被我们的镜头全部换掉。

## ⚠️草稿阶段看什么、不看什么

草稿阶段只判断四件事：**构图、感觉、情绪、节奏**。
**不判断像不像**（脸像不像、装甲细节、材质精不精致）—— 这些在后面的 pro 精图、Seedance 正式版和 Zaoeyo 的美化阶段再解决。
草图丑没关系，情绪不对才有关系。

### ④ 剪辑表 —— 纯文字定节奏
`剪辑表.txt`：一行一段（开始时间 / 素材 / 速度 / 备注）。Leo 直接改几行，或者在对话里说「第 N 段换成……」。
`python tools/edl.py preview` → 不叠效果的 480p 预览，整首大约 20 秒出 → 用眼睛和耳朵看节奏和感觉。
素材可以写：原片的某一秒、第二章素材、我们的样片、一张静帧、一张文字卡（还没有画面的地方先用一句话占位）。

### ⑤ 每个镜头挑工具
| 镜头类型 | 怎么出 |
|---|---|
| 一般镜头 | **Seedream flash 草图** → 方向对了 → **Seedream pro 精图**（带设定图保持她一致）→ **Seedance 2.5 样片**（480p draft）→ 满意 → 用样片的 task id 出**正式版**（构图运镜继承下来；要后期就出 mov）【Seedance 这条路还没真跑过】 |
| 碎裂 / 重组 | **我们自己的数学粒子**（`tools/particle_*.py`）：每个点都是真的动力学，点数守恒。Leo 的要求：碎裂要**短、猛**，是**身体本身受力**（冲击、后仰），不是一张静止照片被挖洞。粒子 v3 已出（`样片/07_粒子_吸气炸碎_v3.mp4`），v4 计划：她全身用点画，碎裂落在 drop 上 |
| 需要严格构图 / 走位 | **Tripo 白模 + Blender**：①当**镜头指导**（潦草摆好机位 → 渲首帧 / 首尾帧 → 交给 Seedance 补质感）；②或者直接 Blender **渲成片**。Tripo 白模 10 积分、两分钟出一个（实测）；Blender 这一段还没开始【没验到】 |
| 记忆插入 | Cortana 的回忆、John 的背影、人物特写里抬头 / 凝望 —— 1–3 帧的 blink，或者一段完整镜头 |
| 原版 MV | **只当脚手架**：先占住节奏，按段换成我们的，**最终全部换掉** |

### ⑥ Zaoeyo 的美化
我们出的是「结构对、情绪对」的画面；光晕、调色、质感、最后那一层好看，交给 Zaoeyo。
分工原则：生成模型只负责「她长什么样」；粒子和规则由代码按真实动力学算（HUD 上的数字都是真的）；美化交给人。
给 Zaoeyo 的素材尽量出 **mov（yuv444p）** 或带透明通道的 png，方便调色和合成。
