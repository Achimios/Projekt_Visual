画面语汇：这部片能用的**每一种画面**一张卡（不是每个样片一张）。卡上的图 = 代表样片的接触表 / 静帧，想换就把卡片 `_pics_` 里的图换掉。

每张卡：是什么 → 能表达的情绪 / 故事功能 → 怎么做（工具或来源）→ 可调的大方向 → 适合放哪 → 现状。最后一节「最终想要的」留给👤自己写。

用法：剪辑表里要用某种画面，就把卡片剪切 / 复制 / 传送过去；代表样片 / 工具是引用（📎），点开就是原文件。
