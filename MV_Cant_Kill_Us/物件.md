# 物件：有实质内容的元素，以及它们在全片里怎么一次次推进

> 起草：Eidolon，2026-10-21（初稿，👤逐条改）。
> 为什么要有这份：草图多是「象征」（一个人、一束光、一团碎片）。观众能认出来、会反复出现、每次有进展的**具体东西**，才是实质内容。
> 和别的文件的关系：`Thymos.md` = 为什么（先验，保持短）；本文件 = 用什么（物件和它们的进展）；`情绪大图/草案.json` = 每段画面；`剪辑表.txt` = 精确到帧。效果的数学在 `4_Eidolon/_设计/效果库.md`。

| 物件 | 是什么 | 意味着什么 | 出现在哪（声音锚点） | 每次的进展 |
|---|---|---|---|---|
| ⭐克拉尼板（或 MEMS 双翼，二选一，👤定） | 振动板上的沙 / 微电路的梳齿谐振器 | 她的「心跳」在重新校准 | **抽搐音**（👤纠正后，在 other 分轨）：drop1 1:03 / 1:15，drop2 2:19 / 2:32，drop3 3:57–4:00 三次弱回声 | 模式一阶阶升高 → 越来越有序 → 最后一次，沙子排成她的脸（接 drop3 重组） |
| 磁流体尖刺 | 黑色液体在磁场下竖起六角尖刺 | 外来意识（先行者的残响）的引力，带敌意 | 狂语段 77–115 s 的变体抽搐 | 尖刺越来越高、越来越逼近她；breakdown 时塌平 |
| HUD 一行字 | 学 Halo opener 的 `CREW SURVIVING: 1` | 一行数字讲完一件事 | 每段一行，落在乐句边界 | `SIGNAL: 1 / 1` → `INTEGRITY 38%` → `REMNANT VOICES: 2,114` → `INTEGRITY 0%` → `MASS CONSERVED` → `DISTANCE TO JOHN: 0.0` |
| 被烧开的门（第二章） | 她被入侵的那扇门 | 伤口、起点 | 记忆 blink，每段 1–3 帧 | 越来越清楚；drop2 时第一次完整看到 |
| John 头盔的划痕 | 面罩边上的一道旧划痕 | 他是具体的人，不是英雄符号 | 06「一个名字」、13「归途」、14 结尾 | 先只在反光里；最后手套伸出时划痕在画面里 |
| 她的脸 | 碎裂时留到最后的那一块 | 「还记得自己是谁」 | 每次碎裂 | drop1 留下（边缘也碎，不是光滑椭圆）→ breakdown 也散了 → rebuild 第一个回来 |
| 一粒红点 | 全片唯一的强调色 | 「此刻」/ 心 / 危险 | 每个画面只有一处 | 冲击点 → 吸引子笔头 → 狂语段变多（唯一一次） → 冲顶的汇聚点 → 落进 John 的掌心 |

## 👤2026-10-21 定
- 抽搐音：**先机械后有机** —— drop1 用 MEMS 双翼（机械、精密、脆），drop3 用克拉尼（声音变成有机形状，最后排成她的脸）；drop2 是过渡（MEMS 开始「长」出克拉尼纹样）。
- HUD 用**英文**。
