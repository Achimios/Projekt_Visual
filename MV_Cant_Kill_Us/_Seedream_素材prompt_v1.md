# Seedream 素材 prompt v1（2026-10-26）

**用法**
- 每条都带一张 Pinterest 参考图当风格锚点，每条出 3–4 张，再挑。
- 统一后缀：每条 prompt 末尾都加上同一段【风格后缀】，全片的色调就能统一。

⚠️ **版权**：不写 Cortana、Halsey、Halo、UNSC 这些名字，也不照抄它们的标志性设计。Cortana 的标志是紫蓝色全息加满身电路纹，Halo 的 AI 芯片也有固定的形状。我们只做原创的「全息 AI 女性 / 科学家 / 实验室」。参考图同理：取光影和质感，别取角色的脸和标志。

⭐ **给示波器用的素材**（要描轮廓的）要满足三点，上次侧脸头顶被画框切平就是没满足：
- 纯黑背景；
- 主体完整，头顶留白；
- 侧光，边缘清楚。

**【风格后缀】**
```
cinematic sci-fi, photoreal, cold grey-white palette, deep black background, a single small red accent light, soft volumetric haze, shallow depth of field, 35mm film grain, no text, no logo
```
