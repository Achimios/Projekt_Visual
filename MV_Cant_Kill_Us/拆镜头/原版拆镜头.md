## 二、原版的视觉语法（我们要学的是语法，不抄画面）
- **黑底 + 低调光 + 单色**（冷灰为主），只有少数镜头给**红 / 橙**（宝珠、火、标志）—— 和攻壳那条「一个镜头一个主色」一致。
- **超近景的材质**：鳞片、皮肤、金属、水滴。看不清整体 = 悬念。
- **镜像万花筒**（0:28、0:32、1:48、3:16、4:32 军团）：一个物体对称复制成图腾。
- **碎裂 / 颗粒化**：盔甲、脸、刀碎成颗粒飘走（3:24–3:56、4:04）。标题「打不死」的视觉反面 —— 碎了还站着。
- **圣几何标志**（两圆相交 + 三角）贯穿全片：地面浮雕、火焰、火球、眼睛里的倒影。

## 三、重做时每类镜头用什么做（初判，等用户定概念后再细分）
| 镜头类型 | 工具 | 理由 |
|---|---|---|
| 角色（人 / 盔甲）+ 动作 | Blender（模型 + 骨骼），动作【未验】可试 kimodo / KimodoToBlender | 最难的一类；角色资产要先定来源 |
| 碎裂 / 颗粒化 / 点云溶解 | Blender 几何节点 | 程序化、可复现；顺带出运动矢量给现场 |
| 火、烟 | Blender 模拟（慢）或现场 shader 近似 | 先用 shader 预演，定稿镜头再模拟 |
| 超近景材质（鳞片、皮肤、水滴） | Blender | 材质 + 微距景深，「镜头本来就会这样」 |
| 场景（寺庙、隧道、光柱） | Blender；简单的可 three.js 实时 | 隧道 / 光柱适合现场实时演奏 |
| 镜像万花筒、标志发光、故障 | **现场（VisualProcess）** | 「信号」类，跟拍点实时打 |
