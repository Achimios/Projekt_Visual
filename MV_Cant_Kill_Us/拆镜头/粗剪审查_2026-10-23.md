## 1. 重复在哪（v4）

- **原片脚手架 9 段 = 15.0 s**（全长的 15%）；但集中在 drop1 + 狂语：51.5–97 s 里占 **13.4 / 45.5 s ≈ 29%**。另有 3 张静帧慢推（70.72 / 78.72 / 93.12，共 4.5 s）—— 都在音乐最满的地方（§16：静态 = 效果测试，不是成片状态）。
- **卡拉比丘家族在 70.7–97 s 占 12.2 / 26.3 s ≈ 46%**：`11b_全局_v2` 用了 3 次（@0 / @0.5 / @2，0.5–0.87 s 和 2–2.52 s 这两段**同一批帧放了两遍**），加 11c、两张卡拉比丘静帧。86.30 那次备注自己写着「借用画面，声音不同步」。
- **四维插入 = 同一种运动连着出现**：57.94 / 61.10 / 67.50 / 73.90 / 89.96，每 ~6 s 一次「先快后缓」。缓的尾巴就是节奏对比里 57.4–61.7、67.2–70.8 两段「音乐满、画面静」的来源。
- 回想段 19.58–32.30 是一个 12.7 s 的长镜头（内部有视角切换，但没有 v2 那种闪帧串）。
- 重复但**是故意的**（保留）：MEMS 09c 两次 = 抽搐音两次（同一声音 = 同一物件，第二次接着放）；红色警报 blink 两次（32.30 预告 → 89.92 被入侵）。
