## 几何语汇 / 符号系统
- ⭐**模块字体**：拉丁字母、数字、片假名全由同一套笔画模块拼成 —— 横笔、竖笔、四分之一 / 半圆弧、圆点、斜切的平行四边形。字是「组装出来的」，所以可以只显示一部分、可以拆、可以把笔画换成别的字的笔画。
- **点阵底网**：极细的点阵（约 24 列）铺在暗底上，是全片的「坐标纸」，元素落在网格上。
- **标签框**：细线矩形里写一行极小的等宽字（讲者名 / 类别）—— UI 的语气。闪一下（填实 1 帧）当强调。
- **斜线**：45° 细线和带拖尾的碎片，给静态构图一个方向感。
- **字阵**：字形排成规则的行列 → 像一块信息面板 / 一群声音。行上的横条 = 「被选中」。

## 运动语法
- **笔画级动画**：动画的单位是笔画，不是整个字。笔画画出（draw-on）→ 字成立 → 笔画收回（draw-off）或者一根根掉落（animatic 里很清楚：字形笔画随机地一根根消失，剩下的不动）。
- **边转边长的弧**：弧的起点在转、长度在长，两件事同时发生 → 有张力。之后从一端收回 → 不对称的退场。
- **换色代替剪辑**（彩色版）：同一构图在拍上整套换色。⚠️这是全局效果，我们不学（👤「鼓点不推全局」）；黑白 animatic 里对应的是「标签框填实 1 帧」—— **作用在一个有形的元素上**，这个能学。
- **高潮 = 前面所有构件的叠加，结束 = 收缩成一个点 / 一个小方块**（1:30–1:44）。和 Halo 4 的「坍缩成一个光点」同一个语法。
- **镜头几乎不动**：动的是元素自己，偶尔有整屏横移 / 斜移的色带。

## 配色与排版
- 正片：暗底（近黑偏紫）+ 高饱和整屏色块（珊瑚红、青、黄绿、紫、群青）轮换。
- animatic：纯黑底 + 白色字形 + 灰色点阵 —— 我们的方向。
- 排版：大字（占画高 1/4–1/3）+ 极小的等宽标签（占画高 1/60）两种尺度，**没有中间尺度** → 对比强。（和 The Crew 碎裂「只有尘埃和整行条块、没有中等碎片」是同一个原理。）

## ⭐值得学的手法：数学 / 算法 + 参数估计
| 手法 | 数学 / 算法 | 参数估计 | 我们怎么改成「说真话」 |
|---|---|---|---|
| **模块字体 + 笔画组装** | 字形 = 网格上的笔画列表 [(类型, 格坐标, 方向)]；每笔一个出生时刻 t_k，位置从偏移 d_k 以先快后慢缓动到位；弧笔画同时做 θ0(t) 旋转 + Δθ(t) 生长 | 一笔 4–10 帧；笔与笔错开 1–3 帧；弧边转边长 ~20 帧、转过约 90° | 笔画的出生时刻 = 真实起音；HUD 那一行（真实数字）由笔画拼出来 |
| **笔画剥落** | 每笔一个随机寿命（或按某个真实量排序），到点就消失（不淡出），剩下的不动 | animatic 里一个字 ~1 s 内掉光，间隔不均匀 | 掉落顺序 = 真实的东西（例：按被吸收的顺序、按频带） |
| **字阵 + 行选择条** | R×C 网格，每格一个字形；选中行 = 一条覆盖该行的实心条，条的左右端各自按缓动伸缩 | 条的开关 2–4 帧；约 8 行 × 16 列 | **每格 = 狂语段一个真实起音**（142 个声音），字形由该起音的频谱特征决定；吸收段每个起音选中一格 |
| **标签框填实 1 帧** | 框 → 实心 → 框，1 帧（或 2 帧） | 1 帧 | 只在真正的事件（某个数字变化 / 某个拍点）上闪，且只闪那一个框 |
| **高潮 = 叠加，结束 = 收缩成点** | 所有元素以同一锚点做缩放 s(t) → 0 | 约 2 s 收完，最后小 logo 停 ~6 s | 收缩的锚点 = 红点（「此刻」） |

## 别学的
- 整屏换色 / 整屏色块闪（全局、廉价、和我们的冷灰白冲突）。
- 片假名 / 拉丁混排的装饰性 —— 原片是为东京站点设计的身份，我们没有这个语境；我们的 HUD 是英文（👤定）。
- 「字只露一部分」的纯形式感，如果不表达任何东西就别用。
