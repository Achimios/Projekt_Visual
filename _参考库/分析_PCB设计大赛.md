## 一、这片子本身怎么动（便宜的运动词汇）

**结构**：几乎全是**静帧**（各获奖板的 CAD 截图）。节奏是模板化的
**「约 1 s 转场 + 约 4 s 定格」，每块板 5 s**，转场起点大多卡在 x.0 / x.5 秒整数上。

**怎么测的 / 判据**（降采样 256×144 灰度，逐帧差分）：
- **硬切**：单帧差分尖峰，前后都≈0（25.3 s 切黑、65.6 s 片尾切黑）。全片真硬切只有这两三处。
- **溶解 / 淡入**：差分低而平（≈1–2，持续约 1 s），亮度单调变化，没有尖峰（7.2、9.6、12.3 前半等）。
- **冲入 / 拉远 / 旋转 / 滑入**：差分高而宽（15–35，持续 1–3.5 s），结构差分也高，相位相关峰值掉到≈0（=画面在整体移动/缩放）。
- **定格段**：对首尾帧做「缩放 × 平移」暴力搜索，**最优解全是 scale 1.000、位移 0** → 定格里**没有 Ken Burns 慢推**，残余差分只来自侧边文字淡入和压缩噪声。
- ⚠️ 每 5 s 整点有一帧≈0.5 的小尖峰：是编码关键帧，不是镜头事件。
- ⚠️ 全局运动估计（Fourier-Mellin）在逐 3 帧间距上分辨不出这些慢变，旋转/缩放的定性是**看帧**定的，不是算出来的。

其中**冲入满屏细节 → 拉远看全貌**（01→02、19→20）最有效：先看到「乱」，再看到「整体有秩序」，

**反面**：转场类型太多、没有逻辑，像 PPT 模板轮播 —— 我们用的时候**选一两种、和内容绑定**。

## 二、视觉词汇（片子里实际有的）

| 元素 | 片中样子 | 在哪看 |
|---|---|---|
| **BGA 阵列** | 规则点阵焊盘，常被铺成一整块紫/绿色方区 | 43.0 紫区、56.0 |
| **BGA 扇出（fan-out）** | 从点阵中心向外**放射**的密集走线，像日冕 / 神经元 | ⭐37.5 圆形板（全片最强的一张）|
| **扇出成束** | 出了 BGA 后线成束、斜着长距离跑，束与束交叉（不同层叠出来的） | ⭐33.0 粉色斜线束 |
| **蛇形等长（meander）** | 一排平行线上有手风琴式的锯齿起伏，用来补长度 | 16.6 中央 BGA 两侧 |
| **差分对** | 两根贴得很近、同步拐弯的线 | 56.0 局部、29.0 青色层（压缩后不太清）|
| **过孔场** | 密集小圆点，常在铺铜里成片 | 21.6、56.0 |
| **45° 拐角** | 走线几乎只有 0/45/90°，这是 PCB 一眼可辨的"笔迹" | 处处 |
| **铺铜（copper pour）** | 大块填色区域，边缘是不规则多边形，中间被焊盘/过孔挖出孔 | 21.6、24.0、53.0 |
| **粗电源线 / 分区线框** | 黄绿色粗线把板子划成几个区 | ⭐53.0 |
| **层色** | 每一层一种饱和色（红/蓝/绿/青/紫/黄），多层叠在一起 = 片子的主色调 | 3.0 标题背景 |
| **丝印 / 标注** | 片中不明显（只有零星位号），以白/黄小字为主 | — |
| **3D 叠板** | 等轴测 3D 渲染的多层板 | 17.7 |
| ⚠️**飞线 / 鼠线（ratsnest）** | **片中没有** —— 全是已布完的板。飞线要靠记忆 / 别的参考：CAD 里是细直线（常白/黄），点对点跨板乱连 | — |

**层色惯例**（行业常见、各家 EDA 可自定义，片里各板都不一样）：顶层红、底层蓝是最普遍的默认；
内层随意分配绿/黄/紫/青；黑底；高亮网络用白/亮黄。⚠️**多层全开叠色是"乱"的来源**，
单层显示才"干净" —— 这本身就是一个可调的情绪旋钮（层数 = 信息密度）。

## 三、能程序化生成的 & 怎么做

| 元素 | 算法 | 生长感从哪来 |
|---|---|---|
| **飞线（未布线状态）** | 每个网络的引脚做**最小生成树**（Prim/Kruskal）→ 直线连 | 一次画满 = 乱麻；逐条出现也可以 |
| **布线生长** | 网格上 **Lee 算法**（BFS 波前）或 **A\***，代价里加 45° 拐角奖励、过孔惩罚 | ⭐**先画波前扩散（一圈圈涨潮），找到终点后回溯出一条线** —— 「搜索」本身就可见 |
| **自动布线整体过程** | 按网络优先级逐条布；已布的线成障碍；失败就"拆线重布"（rip-up & reroute） | 有挣扎、有反悔、有最后的秩序 |
| **BGA 扇出** | 点阵 → 每个焊盘就近打过孔（dog-bone）→ 按象限向外放射 | 从中心往外一圈圈长出去 = 日冕 / 开花 |
| **蛇形等长** | 一组线算长度差，短的插入振幅/节距可调的锯齿 | 能看见「为了和别人一样长而弯腰」|
| **铺铜** | 区域多边形 − 走线/焊盘的偏置（Minkowski 外扩）= 洞；或者网格泛洪填充 | 泛洪从一点漫开，绕开障碍 |
| **差分对** | 一条中心线 → 左右偏移两条，拐弯同步 | 两根线永远并行 = 陪伴 |
| **层叠** | 每层一张图、一种色，加法混合 | 逐层点亮 = 复杂度递增 |

实现上：2D 网格 + Canvas / numpy 足够，**不需要真 EDA**。走线全部限制在 0/45/90° 就自动"像 PCB"。

## 四、怎么承载情绪 / 故事

- **飞线乱麻 → 布线后的秩序** = 「整理 / 重组 / 想通了」。飞线直线互相穿插（焦虑），布完后全部顺着网格走（平静）。
- **Lee 波前** = 「在黑暗里摸索」：波一圈圈扩出去，碰到墙绕开，摸到终点的那一刻回溯出一条亮线 —— 有"顿悟"的节拍点。
- **拆线重布** = 「推翻重来」：一条线被拔掉，别的线因此能走通 —— 牺牲 / 让路。
- **BGA 扇出** = 「一个中心，向外辐射」：心脏、太阳、权力中心；反向播放 = 一切收束回一点。
- **蛇形等长** = 「为了同步而绕远路」：为了和别人同时到达，自己多走弯路。
- **差分对** = 两个人。一对线分开（一根被障碍隔开）就是分离。
- **铺铜漫开** = 淹没 / 占领 / 地盘。
- **多层叠色全开** = 信息过载；**逐层关掉只剩一层** = 冷静下来、聚焦。
- **冲入细节（乱）→ 拉远看全貌（有序）**：原片已经无意中用了这个对比，我们可以有意用。

## 以后用在哪

- **Dune 预告片**：沙丘 / 香料 / 预知 —— 扇出放射当「预知的分叉」，单色（沙金 / 黑）布线网络当「命运路径」；Lee 波前当「香料视野」一圈圈展开。走克制的单层单色，别用原片那种彩虹叠色。
- **Billie Eilish MV**：低饱和、亲密、不安 —— 飞线乱麻 = 脑子里的噪声，差分对 = 两个人的关系（并行 → 被隔开），蛇形等长 = 「为了跟上别人绕的远路」。可以只用 1–2 种颜色 + 黑。
- **Ash Thorp 风纯 2D 动态设计（MODULAR 那种）**：最对口。网格 + 45° 线 + 模块化分区本身就是那种美学；用 Lee 波前 / A\* 生长当主运动，条带切片 / 方块遮罩当转场（和网格同构），冲入→拉远做大节拍。

⚠️ 没做 / 没验的：没测原片旋转角度和冲入倍率的精确值（只看帧定性）；
片里没有飞线，飞线的视觉参考还得另找；原片压缩重（细节裁切可见方块），差分对、丝印细节看不清。
