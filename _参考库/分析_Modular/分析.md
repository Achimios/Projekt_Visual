## 一句话
**一个镜头到底的「模块拼装」**：浅灰纸底上，一套很小的几何词汇（方块、四分之一圆、同心弧、点阵、阶梯条、渐变色条）在一张看不见的网格上不停地长出来、缩回去、互相替换，2:43 里只有 7 处硬切。结尾 2:28 起 10 → 0 倒数。

## 几何语汇 / 符号系统
- **网格量化**：所有元素的位置、尺寸都落在一张看不见的网格上（方块边长是格子的整数倍，四分之一圆的半径 = 1 / 2 / 3 格）。所以无论多少东西叠在一起都不乱 —— 秩序来自网格，不来自构图。
- **极小的词汇表**：方块、四分之一圆（实心 / 同心弧）、圆点、点阵（实心点 / 空心方点）、点线框、加号、阶梯条、渐变色条。大约 8 种，全片反复组合。
- **四分之一圆是主角**：它既是「字形的笔画」（拼 J、拼数字），又是「刻度盘」（同心弧），又是「转场」（扇形扫开）。一个形状三种身份。
- **点阵 = 数据**：点阵常以「掉落 / 稀疏化」出现，像数据在散开。
- 品红小圆点：全片少数几次出现，像一个「此刻」标记（我们的红点也该这么用）。
- 几乎没有文字（只有极小的标签字）。

## 运动语法
- **生长代替出现**：没有淡入。四分之一圆按扇形角度扫出来（角度 0 → 90°），条按段伸出来，方块按阶梯一级级冒出。退场同理：**缩回 / 分段收掉 / 收成一个点**，不淡出。
- **先快后慢**（上面测的两段式）：前 3 帧走掉大部分，之后指数缓到停；停了也有更小的元素在继续长 → 画面从不完全静止。
- **一个时刻只有一件大事**：每次只有一个主元素在大幅运动，其余元素是小幅的余波（点阵飘、弧在转）。
- **转场 = 替换**：上一组元素缩回的同时下一组从同一个锚点长出来（例：0:41「+」→ 四点 → 空心圆 → 下一个构件），所以 2 分多钟几乎不用剪。
- **连续拉远**：嵌套点线方框 → 倒数段，镜头一直在拉远，数字一个接一个从「大」退到「小」，像穿过一串套娃。
- **节奏**：大事件大约每 3 拍一次（倒数段量出来正好 3 拍一个数字）；硬切只给最强的几下。

## 配色与排版
- 浅冷灰纸底（带极淡的纸纹）+ 纯黑形状 + **渐变色条**（蓝→品红→红、黄→青）当唯一的彩色。彩色只出现在「条」上，形状本身全是黑白。
- 极少文字；有字时是极小的无衬线标签，靠在元素边上。
- 构图：元素多数贴着画面中心竖轴 / 对角线排，左右大量留白。

## ⭐值得学的手法：数学 / 算法 + 参数估计
| 手法 | 数学 / 算法 | 参数估计（来自上面的测量 / 目测） | 我们怎么改成「说真话」 |
|---|---|---|---|
| **扇形扫出（四分之一圆生长）** | 环形扇区 {r0 ≤ r ≤ r1, θ0 ≤ θ ≤ θ0 + Δθ(t)}，Δθ(t) = Δθ_max · ease(t)；同心弧 = 多个 r 区间、各自延迟 | 90° 扫完约 6–10 帧；同心弧之间延迟 1–2 帧 | **相位环**：Δθ = 2π × 真实相位（拍 / 小节 / 乐句 / 段落四个时间尺度），一圈 = 一拍 / 一小节 …… |
| **两段式缓动（先快后慢）** | 速度 v(t) ∝ a·e^(−t/τ1) + (1−a)·e^(−t/τ2)；位置 = 积分，归一到 1 | τ1 ≈ 3 帧（每帧 ×0.72），τ2 ≈ 9 帧（每帧 ×0.89），a ≈ 0.6；全程 ≈ 18 帧 | 所有「到位」动作都用它；起点放在真实起音上 |
| **网格量化** | 位置 / 尺寸 = round(x / g) · g，g = 画高 / 18 左右 | 目测 16–20 格竖向 | 我们的字形和数据条都落在同一张网格上 |
| **阶梯条（分段伸缩）** | 条长 L 量化到 k 段，每段宽度不等；伸出 / 缩回按段跳（每段 1 帧） | 段数 3–6，段宽比 ≈ 1 : 0.6 : 0.3 | **阶梯频谱条**：每根条 = 一个频带的真实能量，量化到格子，按段伸缩 |
| **替换式转场** | 退场元素收缩到锚点 p 的同时，入场元素从 p 以同一缓动长出 | 两个动作重叠 3–6 帧 | 字阵里「被吸收的那一格」收成一个点、点飞走 |
| **连续拉远（套娃）** | 对数缩放 s(t) = s0 · e^(−k t)，每过一个周期 T 换下一层，层间比例 e^(kT) | 每 3 拍一层；一层内约缩到 1/3（目测）→ k ≈ ln3 / 0.97 s ≈ 1.1 /s | **倒数**：每拍一个数字（数字 = 离 drop 还剩几拍，真数），数字之间用同一条对数拉远连起来 |

## 别学的
- 渐变彩条和高饱和配色（我们是冷灰白 + 一个红点）。
- 浅底（我们是黑底；浅底的「纸感」在本片的高维虚空里不对）。
- 纯装饰的点阵掉落 —— 它在原片里不代表任何数据（= 我们要避免的「好看但不说话」）。

## 可信边界
- 切点检测只能抓硬切；本片绝大部分变化是画内的，**「7 处硬切」不等于「7 个镜头」**。镜头列表是按每秒接触表人工分段的，时间精度 ±0.5 s。
- 衰减常数只在 0:42+12 一处测了，用的是全帧平均帧差（混了多个元素），不是单个元素的轨迹。
- 「每个数字 3 拍」只量了 10/9/8/7 四个数字。
- BPM 是频谱通量自相关估的，没有对照原曲信息。
