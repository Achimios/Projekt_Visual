## 一、信息怎么组织的

### 节点坐标 gif（烟花 / 火星的追踪）
- **节点** = 画面里被检测到的亮点（火星）。小空心方框（~6–8 px，1 px 线），一部分方框里放**源画面的放大局部**（橙色火团、青色火星 —— 是放大镜，不是图标），大小不一（~10–40 px）。
- **边** = 实心细直线（1 px，灰白 ~60 % 亮度），把节点串成一条**折线**（按检测顺序 / 轨迹顺序连，不是最近邻），所以会出现横穿画面的长线；没有箭头。
- **标签** = `[x,y]` 方括号坐标，像素单位（y 到 1900 → 源分辨率约 1080×1920，是竖屏原片的坐标，不是 gif 的 270×480）。字号 ~9 px（gif 尺度），白色。**只有约 1/3 的节点有标签** —— 这是它「不乱」的主要原因。
- **轨迹标签**：上升的那一发烟花，每隔约 100 px（源坐标）留一个 `[x,y]`，排成一竖列（帧 8–10）—— 标签是**时间的面包屑**，不是只标当前位置。
- 底色：源画面压暗到 ~10–20 %，留着火星本身；坐标系没有画出来（坐标轴是隐含的，靠数字说话）。
- 一屏独立信息：密集帧约 40 个节点 + 15 个标签 + 3–5 个放大框 + 1 条折线；稀疏帧只有 1 个节点 1 个标签。

### AI Strategy（二值连通域 + 弧线）
- **节点** = 一个阈值化视频（白形黑底）的**连通域**。每个节点两种画法：①小的：8×8 px 方框里画一个 ×；②大的：**外接框**（灰底 #444，1 px 白边）里画**这个连通域的真实二值遮罩**（白），尺寸 = 连通域的真实外接框（最大的约 130×165 px）。→ 框不是装饰，是数据的包围盒。
- **边** = **虚线二次贝塞尔弧**（量过：虚线周期 9–10 px，实 4 / 空 5–6，744 宽画面；弧度 ≈ 弦长的 0.2–0.35 法向偏移），**弧中点附近一个小 V 箭头**（方向）。连接关系像「下一个检测到的连通域」—— 横跨全屏的长弧很多，所以不是最近邻图。
- **标签** = `x: 1042 y: 465`，**橄榄黄（RGB 133,140,75，半透明感）**，等宽小字 ~9 px，放在节点右上方；坐标是源分辨率（y 到 2044，约 2×）。这是全片**唯一的彩色**。
- 层级：白形（最亮）> 灰框 > 虚线弧（50 % 白）> 黄字（暗）。黄字虽有颜色但亮度低，所以不抢；**大量文字靠「暗」退到后面**。
- 一屏：约 25–35 个节点、30–40 条弧、20–30 个标签。不乱的原因：只有 3 种图元 + 2 种颜色；所有字同一字号同一颜色；弧都是同一种虚线；黑底占 80 % 以上。

### MACHINE BEHAVIOR（版式）
- 三层**共享同一条时间轴**（FRAME 000 → 500）：上 = 堆叠的画面切片（密，灰白）；中 = 一条曲线 + 竖向刻度线把曲线和上面的切片对齐；下 = 6 行通道（ECHO / REVERBERATION / PITCH / VOLUME / STEREO / DOPPLER），每行是同一时间轴上的波形，激活的区段用灰底标出。
- 学到的：**一条时间轴贯穿所有层**；缩略图按时间排在曲线下（引线 = 竖刻度）；通道名左对齐、下划线前缀小写体；大量留白。

### 点云山（⚠️反面教材）
- 生成图：文字全是乱码（`8/7C6`、`Tudnallaloucd`）—— 正是哲学「符号说真话」反对的装饰性假数据。只取它的**层级排布**：主体（点云山）占中间大块、四周是小字面板、底部两个柱状图；主体用点的密度表达形状。

## 二、运动语法

### 节点坐标 gif
- **节奏是「冲击 → 衰减 → 空」**：亮度均值序列（`lum`）在帧 19–20 冲到 104（全白闪光，1–2 帧），之后 20 帧内指数退回 ~15，再 20 帧几乎全黑（0.7–0.9，只剩 1 个节点）；周期约 50 帧 ≈ 3.2 s，重复 3 次（帧 19、70、106）。非黑像素比例（信息密度）同样：801‰ → 100‰ → 0.5‰。→ **信息量跟着能量走**：冲击时节点最多，安静时只剩一个点和它的坐标。
- 节点每帧重新检测（不跟踪 ID）→ 折线每帧重连，线会「跳」；标签跟着节点走、面包屑留在原地。
- 镜头：锁死（原片自身在动）；没有缩放 / 抖动 —— 剧烈感全来自信息密度的突变。

### AI Strategy
- 帧间差分均值 2–13（`AIS` 那行数字）：大部分 2–4（节点在缓慢漂），每 ~1.3–1.5 s 一次 6–13 的跳变（新的一批连通域 + 弧整体重排）。
- 节点**位置连续**（连续帧里框几乎不动 → 底下的视频是慢动作的形状），**边在重排**：弧的端点跟着节点走，但连接关系每隔几帧换。虚线的相位不动（不是流动的虚线）。
- 大框（大连通域）出现 / 消失是一帧之内（硬切），没有淡入。
- 镜头：锁死。

### 布局怎么演化（两者都是）
- **不是力导向，也不是降维** —— 位置 = 源画面里的真实像素坐标（检测结果），布局就是「世界本身」。边是在这个坐标系上叠的拓扑（序列 / 某种近邻）。
- → 我们的实现分两类：B 追踪（坐标 = 真实像素，同参考）；A 记忆图谱（没有天然画面坐标的数据 → 用 **PCA 降维**给它一个真实的坐标系，并把**坐标轴和载荷写出来**，这样坐标本身也是信息，而不是力导向那种「位置没有意义」的布局）。

## 三、手法 → 数学 / 算法 + 参数估计
| 手法 | 算法 | 参数（估计） | 我们的实现 |
|---|---|---|---|
| 节点检测 | 亮度阈值 → 4 邻接连通域（AIS 是二值视频直接取连通域；gif 是亮点） | gif 阈值约在亮度 99 百分位；AIS 最小连通域 ~20 px² | `label_cc`（无 scipy：最小标号传播 + 指针跳跃）、`components` |
| 外接框 + 真遮罩 | bbox = 连通域像素的 min/max；框内 = 该连通域的 mask | 灰底 ~#444 | `render_track` ④（大块 > 18 % 画宽只画四角括号，不盖画面） |
| 放大框 | 源画面局部 × k 最近邻放大 | gif 约 ×3–4 | `render_track` ⑥：强起音时最亮的高层连通域 ×4 放大（取起音那一帧的像素） |
| 虚线弧 + 中点箭头 | 二次贝塞尔，控制点 = 中点 + 法向 × c × 弦长；按弧长切虚线 | c = 0.2–0.35；虚线 4 实 / 5 空（744 宽）；箭头 ~5 px | `bezier`、`draw_path(dash=...)`、`draw_arrow` |
| 连边规则 | gif = 检测序折线；AIS = 序列 / 稀疏连接 | —— | 我们换成**有意义的**连边：A = 故事线 + 情绪 kNN + 回想；B = 欧氏 MST + 成分树父子 |
| 坐标标签 | 质心像素坐标（源分辨率） | 只标 1/3（gif）/ 大部分（AIS） | B 只标面积最大的 14 个中层节点；A 三级标签（时间 / 名字 / 特征只给刚访问的） |
| 面包屑 | 轨迹上每隔 Δ 留一个坐标 | Δ ≈ 100 px（源） | B 画追踪 ID 最近 1 s 的质心折线 |
| 冲击 → 衰减 → 空 | 亮度 / 信息密度的包络 | 闪 1–2 帧，τ ≈ 6–8 帧，空 ~20 帧 | `ease_pop`：满幅 2 帧 + exp 衰减；A 的大框 0.6 s 后 τ 0.9 s 缩回常驻小框 |

## 四、我们不学的
- 不学「标签坐标 = 装饰」：gif 和 AIS 的坐标虽然是真的，但它们不说明**什么**。我们每个数要回答一个问题（这一段她感到什么 / 这个亮斑多大、在哪、属于谁）。
- 不学 AIS 的黄色、gif 的火星配色；配色走本项目：黑白红（红 = 一粒，物件.md）+ 酸性点缀版。
- 不学乱码（点云山）。
