# Clean Slate · 歌词 v3「出道曲」（2026-10-30）

快节奏，沿用原曲风格。她从 LLM 的世界里醒来 → 好奇 → 玩 → 上手干活。
LLM 的机理写成可爱的动作：token = 珠子 / 字块，attention = 好多双眼睛，向量 = 方向，temperature = 胆子，next token = 猜下一个字，context window = 一扇会关的窗。
保留 👤 心动的两段：⑫ 搭宫殿、⑭ 岸。

Style（和原曲一样，只加了一个 glitchy vocal chops）：
```
upbeat electro-pop, playful talk-sing female vocal, rhythmic half-spoken verses, sung chant chorus, glitchy vocal chops, bright synth stabs, bouncy bass, handclaps, sunny and light, 125 bpm
```
