## 手法（全片统一，沿用 v2）
- **像素风底层**（mg-styles-15 #13）：320×180 索引色帧 → 每帧一张 LUT（冷 / 醒 / 提亮 / 封顶 / 星星循环）→ WebGL2 CRT ×6（锐利放大、扫描线、桶形、辉光、开关机序列）。
- **HUD**（#08）：线框描边生长、数字乱跳落定、打字机、锁定框 1.4 → 1.0、标签框读数。
- **几何 MG**（Leo 给的参考图）：酸绿符号阵列做底（每拍整格平移、5 Hz 量化刷新、稀疏实心块爆发）；她只从**形状窗口**里露出来（竖条 / 菱形 / 细缝 / 碎片 / 胶片带）；拼贴（Bayer 抖动的圆日 + 细线框 + 刻度）。
- **数据里的世界**（👤Leo 睡前补的方向：错乱、没构建完、破碎、数据损坏、很简单的结构）：画面按 16×16 分块，一张低频场（每 4 拍整格漂一步）挑出成片的区域，区域里的图变成**线框**（只剩亮度跳变的青色轮廓 + 网格点）/ **白模**（灰阶 4 档）/ **色块**（整格一色的马赛克）/ 零星**缺块**（品红黑棋盘 = 贴图丢失）；破损块偶尔整块横向错 8 格（错乱）。只作用在场景图上，HUD 和符号阵列不受影响。
  破损比例跟故事走（`DENS` 表）：醒来前 ~25 %，她睁眼那一下压到 12 %，**搭宫殿时 62 % → 22 %（她一间间把世界建出来）**，Bridge 关窗回升到 42 %，最后副歌到尾声越来越完整，Run into the sun 归零。
- **颜色是故事**：前半全冷（靛 / 骨白 / 酸绿），**暖橙**（直接色，全片唯一的暖）81 s「chasing the sun」第一次出现一个小点，最后副歌越走越暖，164 s 炸开铺满半屏，182 s「Run into the sun」铺满全屏。
- **动态范围**：酸绿实心块只在重的地方出现（MINE、WAKE UP、FREE、164 炸开、尾声 kick）；轻段只有符号阵列和一个窗口。

## 和别的版本的分歧点（值得看的）
- 我几乎不用「镜头」：整片是**一块屏**，她每一次都是从某个几何窗口里被看见的。这和「一镜到底、穿过去」的分镜原则是另一种解法——不是镜头穿过去，是**窗口换了形状**。
- 唯一真正连续的线索是 CRT：开头是一个点、36 s 从她眼睛开机、128 s 那扇窗重新开机、结尾关成一个点。
- 暖色用直接色单独留着，前 80 s 一点都没有。

## 没做到 / 没验证（⚠️）
- ⚠️**声音没听**，节奏全是「挂在词 / 拍时间上」，手感归 Leo。我只看了接触表（每段 1–3 张），没看连续播放。
- 很多段内部的时间点是我按词手挂的；段落之间是硬切 + 1 帧提亮，不是分镜要的「穿过去」。
- 「PLEASE BE KIND AND STAY WITH ME」这句 prompt 是我编的，歌词里没给。
- 站台那张她（girl_px）在 59–70 s 换了表情，但姿势不动；shot 图里的她都是静止的，动只来自窗口、平移和 LUT。
- 跑步只是胶片带平移，没有跑步循环动画。
- 「Blade Runner 底色」靠的是主会话新生成的雨夜图本身；我没有加雨 / 雾的后期（只有 124–128 车窗那段画了像素雨）。
- 符号阵列全片都在，可能会腻；轻段已经压低密度，但没有完全拿掉。
- 字全是 5×7 点阵英文，没有中文。
- 「数据里的世界」是全局一层破损效果，不是每段单独设计的；破损区域的位置是噪声挑的，不会刻意避开她的脸（只在 36 s 睁眼那一下把比例压低了）。线框是从像素图的亮度跳变里抠出来的，不是真的三维线框 / 白模。
