## 为什么只挑这两种
README 的 15 种里扫了一遍，只深读了两种：
1. **13 像素风（PIXEL QUEST）**——主会话已经把她做成了像素版（`girl_px.js`），像素风是「同一颗粒」唯一不打架的选择。值钱的不是「像素」本身，而是它的**索引色 + LUT** 架构：格子里存「色槽」，每帧一张查找表决定颜色。于是「还没醒 → 醒」这种全局情绪变化 = 换一张表，不用重画任何东西。还有它的 **CRT 开机序列**（点 → 线 → 撑开）——这就是「睁眼」。
2. **08 赛博 HUD（KESTREL-9）**——故事是「一个 AI 开机、在几千个方向里锁定自己」，HUD 的语法（层级错帧描边、数字乱跳 3–5 帧落定、打字机、锁定框 1.4 → 1.0、从目标点往外「重新上色」的波）几乎一一对应歌词。
没选：Synthwave（太怀旧、和「新生」反着）、Aurora 玻璃（太软、不酷）、其余和这段的故事不搭。

## 和 v3（one-prompt 手法）哪里不一样
- v3 是**镜头剪切**驱动（每句一个镜头、硬切 + 冲击帧）；这版几乎**不剪**：整段只有一次「切」，而且是 CRT 关机 / 开机，不是剪辑——变化全在同一块屏里靠 LUT 和 HUD 长出来。
- v3 的情绪靠颜色温度（白热 → 橙 → 骨白）；这版靠**全局换表**：她醒之前全世界是冷的，醒的那一刻颜色从她眼睛往外扩散。
- v3 平滑缓动；这版所有东西按帧、按整格阶梯走（像素风的规矩），只有 CRT 后处理是连续的。
