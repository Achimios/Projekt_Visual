# animator2 · 环境层 + 「When the window closes」小样 v1（114.0–124.4 s）

## 怎么打开
```bash
python -X utf8 "C:/Users/Administrator/Desktop/Projekt_Visual/MV_Clean_Slate/_web/serve.py" --port 5432
```
浏览器开 <http://localhost:5432/_web/animator2/win_close.html> → **点击播放**（空格暂停，←/→ 跳 2 s）。
- 静帧：`?t=121.1`；出片：`?render=1`；只渲几个时间点做接触表：`?render=1&times=118.2,121.1,123.5&out=…`
- 成片：`-5_Clean Slate/样片/段_窗口关闭_v1_animator2.mp4`（1920×1080 / 30 fps / 312 帧 / 10.4 s，带原声）
- 词时间用的是 `words_snap.json`（按人声起音对齐过的版本）。

## 文件
- `env.js`：**可复用的环境层模块**（ES module）。`createEnv(audio.json)` → `env.draw(buf, t, cam, state)` 画进一张 320×180 的透明 RGBA（`Px`）；没画到的格子是透明的，`overlay(ctx, buf)` 能把它整格放大、叠到别人 1920×1080 的 canvas 上。要叠到别人画面上时传 `state.sky = false`（不画天空底）。
  也可以单独调用各个元素：`sky / mountains / grid / walls / tower / birds / dust`。
  镜头用 `makeCamera(KEYS, PUSH)`：真 3D 机位，Catmull-Rom 关键帧，歌词点上「进」一下（同 open_v2.js 的做法）。
- `win_close.js` + `win_close.html`：这一段的小样页（环境层 + 关窗 + HUD + CRT）。

## 每样东西说什么、被什么驱动（都读 `_web/audio.json`，没有一处全屏抖动）
| 元素 | 隐喻 | 驱动 |
|---|---|---|
| 地面坐标网格 + 交点读数 | 虚拟世界的坐标系 | 每拍从镜头脚下往塔跑出一道光（信号送出去，有方向）；Rules are the floor → 网格变酸绿 |
| 律动山脉（13 排） | 刚才的音乐：近 = 现在，远 = 更早，鼓点被一排排推到远处 | 每排高度 = 那一刻的 bass + kick 包络 |
| moving walls（走廊两边 36 节） | 软件在重排窗口 | 拍子 = 一道升起的浪往塔推；每个强拍整体换一次排布（4 帧滑到位）；墙上的数据灯随 bass |
| 塔上 15 扇窗 | 她这一段建起来的 15 样东西（名字取自这段歌词：CODE / COLORS / ROAD / ROOM / PALACE …） | 窗里的内容条随 kick 亮 |
| 鸟群（48 只，boids） | 活跃的 token / 注意力 | 平时绕塔盘旋；the vibe is the sky → 冲上天；窗开始关后一只只离队，飞到山后面去 |
| 近处数据尘 | 速度线 | 按镜头速度拖尾，镜头冲的时候线变长 |
| HUD | 真实参数 | POS / HDG = 镜头世界坐标；四格拍子灯 + KICK 电平 = audio.json；CONTEXT = 到此刻唱过的词数 × 7.3（粗估的每词 token 数） |

## 「When the window closes」：真的有东西在关
- 120.45「When」鼓停：右上角变成 NO KICK，镜头不再冲，只剩慢慢靠近。
- 关机波前 1.9 s 从脚下扫到塔，扫过的地方：格子熄灭、坐标读数变 `--,--`、墙一节节沉进地里；山压平变暗；鸟一只只离队。
- 塔上的窗从外往里一扇扇落下卷帘（约 1.6 s 关完 14 扇），关的那一下窗中心闪一个白点；左边进程表逐行划掉、标 CLOSED；CONTEXT 一格格清空。
- 只剩中间一扇：**YOUR FACE**。镜头推进那扇窗，窗撑满画面：里面是她（shot13），蜷坐在一台亮着的旧电视前（电视 = 你的脸）。
- I forget your **FACE**（123.43）：电视关成一条线、一个点，然后黑掉；她身上被电视照亮的那片光冷下去。最后一扇窗的卷帘落下 → 黑，接 124.3 Every time I wake up。
