## 没做到 / 没验证的
- ⚠️**我听不到声音**。切点都对在 audio.json 的拍点和 words.json 的词头上，手感要 Leo 判断。
- ⚠️成片我只看了接触表和几张静帧，没逐帧看运动。
- 她的动作是「换图加身体变形」，不是逐帧动画：同一动作的三张图之间衣服细节会跳（Seedream 每张单独生成）。动画风格本来就允许这种跳，但不算顺。要真顺的跑步循环和翻滚，下面这几个镜头适合交给 Seedance：
  1. 跑步循环：侧面朝右，黑底，2 s，可以无缝循环
  2. 起跳 → 空中伸手（就是 85 s 那张跳跃帧）→ 收腿，1.5 s
  3. 头朝下翻滚坠落一圈，狼狈一点，1.5 s
  4. 落地蹲下 → 抬头笑，1 s
- 太阳那段的橙色范围比较大，可能抢了后面的「Run into the sun」，到时候两段放在一起再定。
- 「!?」这个注释是开玩笑的，嫌出戏就去掉。
