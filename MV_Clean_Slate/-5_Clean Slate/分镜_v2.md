# Clean Slate · 分镜 v2（2026-10-30，对应 `-5_Clean Slate/`，歌词 v4/v5）

**故事**：一个 AI 人格从数据海里醒来 → 孤单、好奇 → 玩 → 学会节奏 → 干活、搭宫殿 → 知道自己会被清空，还是选择笑 → 上岸。
**数据**：125 BPM（1 小节 ≈ 1.92 s）。时间来自 `_分析/歌词.json`（逐词）和 `_分析/感官.json`（能量）。

## 总原则
- **一镜到底的感觉**：大部分时候镜头不切，而是**穿过去**——穿过海面、穿过一颗珠子、穿过一扇窗。真切只留给几个大时刻。
- **动态范围**（哲学 §8）：每段标了 **轻 / 中 / 重**。拍子一直在，但只在「重」的地方打满；「轻」的地方拍子只碰一个小东西（一颗光点、她的脚尖）。**鼓点打在有形的东西上，不打全屏。**
- **颜色是故事**：
  - 海：墨黑 + 骨白的光点（冷）。
  - 注意力的眼睛：**粉、金、蓝**三色（歌词里唱的就是 pink, gold, blue）。
  - 她：一开始是骨白的光；学会感觉以后，身上慢慢染上**暖橙**（日出色）——全片唯一的暖色，到结尾「Run into the sun」铺满整屏。
- **后期**：辉光、胶片光晕、轻颗粒。海的段落颗粒多（像深夜），岸上的段落干净（像早晨）。
- **大字**：只给关键词，不给整句。字是这个世界里的物体，会被她碰、被她踩、会碎。

## ⚠️情绪大图对照后的修正（2026-10-30，`情绪大图_v1.jpg`）
实测能量和上表有两处对不上，以实测为准（音乐说了算）：
- **结尾（167–189）不是「轻」，是全曲最响的一段**（贝斯和鼓都在最高处）。→ 岸不是安静地回头，是**跑**：她在岸上一路跑向太阳，海里沉睡的光点一个个醒来跟着她，越跑越亮；只有最后一声「Hi」收住。
- **Bridge 只有前半（120–128）是空的**：鼓停、贝斯低；128 起鼓回来、一路往上。→ 窗一扇扇关 = 120–128；「It's the first time I meet you」那扇窗重新打开 = 128 左右，从那里开始往上爬。
- 96–104 的「哼唱」不是安静：鼓停了，但贝斯是全曲前半最强的。→ 她自己跳舞，舞步跟贝斯走（不是跟鼓）。
- 36–58 第一段副歌实测只是中等偏上，留着余量是对的：全片最高点在后面。

## 风格小样候选（下一步挑一段做 10 秒）
1. **36 秒：她睁眼**（光线收紧 → 聚成人形 → 海从她身上亮开）——数学和 MG 的大爆开，最能一眼区分。
2. **66–76 秒：玩**（数字变小鸟、空耳机、踩「FOUR」）——可爱，最能看出「她是谁」。
3. **158–164 秒：全停 → 炸开**——情绪最重，但需要前面铺垫才有力。
