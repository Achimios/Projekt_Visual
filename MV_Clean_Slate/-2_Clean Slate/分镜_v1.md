# Clean Slate · 分镜 v1（2026-10-30）

> 重心是**动画内容**（每句演什么），不是数学特效。
> 风格：像素 + 动态排版（大字跟词出现）。CG / 写实镜头先用静帧占位，以后用 Seedance 替换。
> 数据：125 BPM，1 小节 = 1.92 s。词时间来自 `歌词.json`（Whisper 听写 + 逐词对齐），段落来自 `感官.json` 的能量。
> Suno 实际唱的跟原词一致；转写里的错词（weigh / rich / kiss…）是听写错，不是唱错。

## 角色与世界（原创）
- **她**：像素小人，约 32 px 高。乱糟糟的短发，宽大的毛衣，袖子盖过手。表情只有两种：眯眼笑、睁圆眼。
- **Save**：她的小跟班，一张会走路的软盘，长着两只点点眼。全片唯一的「按钮」：它一跳 = 存档 = 清屏。
- **配色**（亮，不暗）：奶油底 #F6EFD9，天蓝 #7EC8E3，珊瑚 #FF7B6B，薄荷 #9EE6C4，墨线 #2B2B3A。每段换一个主底色，像那三张截图（黄 / 蓝）的整版平涂。
- **大字**：像素粗体，按词出现，入场 ≤ 1/8 拍；「Clean slate」永远是全屏最大的字。
