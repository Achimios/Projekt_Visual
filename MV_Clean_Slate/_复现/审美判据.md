# Clean Slate · 审美判据（什么算好、什么算廉价）

> 这不是流程，是**判断用的尺子**。写画面、审接触表、挑版本时逐条对照。
> 👤 = Leo 原话或他定的（只能引用，不能推翻）；📐 和没有标记的 = AI 从实践中总结的，可以推翻。

## A. 运动的纪律

| 判据 | 意思 | 出处 |
|---|---|---|
| **拍点不推全局** | 不要每个鼓点整幅画面放大 / 抖。这是「too cheap, no form」 | 👤 |
| **拍点打在有形的东西上** | 某个元素、某个区块、某个结构（振子 / 裂缝 / 一块被标的区域） | 👤 |
| **动势要有指向或行为意义** | 每次运动的动势都要说得出来"它想干什么"，不是为了动而动 | 👤 2026-11-01 |
| **运动沿结构传播** | 沿晶格的棱传的波、耦合振子的相位波；不是每个点各自加噪（"单纯就是节点在抖动" = 没有结构） | 👤 |
| **镜头不从静止开始，也不停在静止** | 片段开头就带着速度；速度 = 基础速度 + 每个声音锚点一次「进」接「缓」（指数衰减，不归零） | 📐 2026-10-21 |
| **成片里没有绝对静止** | 哪怕很慢也有东西在漂；注意力（亮的标签、被拨的弦、焦点）时刻在换位置。锁机位 = 效果测试，不是成片状态 | 👤 §16 |
| **克制 = 动态范围** | 安静的地方真的安静，大动作留给锚点和段落交界。每拍都触发 = 平铺 = 媚俗。但也不要"太平太 slow" | 👤 §8 |

## B. 颜色的归属（一支片子里颜色要"签合同"）

| 颜色 | 只给 |
|---|---|
| 黄绿（酸绿） | `mine` —— 她选中那根线的那一瞬 |
| 粉 / 金 / 蓝 | 三只注意力头，各一色 |
| 橙 | **她的感觉**：从睁眼开始出现，越往后越多，Run into the sun 时铺满全屏 |
| 暖橙 | 前 80 s **一点都没有**；81 s「chasing the sun」第一个小点；最后副歌越走越暖 |

📐 一个颜色只属于一个时刻/一个东西。观众能靠颜色读出情绪曲线，就说明符号在说真话。
📐 例：Animator2 的品红只留给眼睛和太阳。

## E. 字与信息

| 判据 | 落地 |
|---|---|
| **符号说真话** | HUD 和数字写真实参数（`LIGHT 054%`、`next token 概率`、`T=1.40`）。不做装饰性图表 |
| **字压得少** | 用整张实拍/生成大图大面积铺开，字少而重。巨大的彩色歌词字可以当构图元素（她夹在字中间） |
| **质感 = 有审美的信息量** | 远看一个形，近看一层结构，贴近还有字和数。每走近一步都有奖励（👤 §15） |
| **坏之前先褪色** | 彩色先退成黑白剪影，预告"要坏了" |

## F. 结构 / 叙事

- 歌词定画面，拍子定剪切；轻 / 中 / 重的动态范围要拉开。
- 「全停」是真的全停：鼓全停 → 整帧冻结 ~1.6 s → 下一拍炸开。
- 长静最多 1.4–2 s，之前要么换画面，要么同一画面**在动、在蓄势**。
- 同一个画面别在不合时宜的地方重复（开头那个吸引子不要再拿来当 54–75 s 的坠落）。
- **特效服务叙事**：先问"这一刻故事需要观众感觉到什么"，再问用什么效果、打在谁身上、多重。答案也可以是"什么都不要"。

## G. 明确讨厌的

- 全屏抖 / 全局放大（媚俗）
- 廉价好莱坞味
- 同质化的 AI 味（纯文字 prompt 出来的"平均审美"）
- 滑块式可视化器（音量直接接亮度）
- 每个点独立加噪（没有结构的运动）
- 装饰性的假图表（数字不是真的）
