# Clean Slate · 进度（接手先看这里）

**是什么**：数字偶像的出道曲 MV。她是从 LLM 的数据海里醒来的 AI 人格。纯动画（像素 + MG 几何 + 3D 几何），不用生成式视频。

## 代码（`_web/`，按需写，好用再沉淀）
- `wake_mg.html/js`：⭐MG 版（Canvas 2D）。默认实时跟歌播放；`?t=36.5` 静帧；`?render=1` 逐帧交给 `serve.py` 出 mp4。
- `serve.py`：本地静态服务 + 收帧喂 ffmpeg（本仓库 `Projekt_Visual/.claude/launch.json` 的 `clean-slate`，端口 5430；SimuWeb 那份是旧副本）。
- 渲染：headless Chrome 打开 `wake_mg.html?render=1&out=...`（命令见对话；独立 user-data-dir）。
- `wake.html/js`：早先的粒子版（three.js）——👤否了「太具象、太粒子」，留作技术参考。
- `audio.json`：鼓 / 贝斯包络 + 拍点（Python 预算）。
