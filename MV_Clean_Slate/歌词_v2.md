# Clean Slate · 歌词 v2（2026-10-30）

主题：一个人 + 一个 AI 搭档（Opus），一起把一首歌做成一支可爱的片子。
蹭的热点 = 「人和 AI 一起创作」，但讲的是真事：人给感觉，AI 铺满细节；AI 听不见音乐，只能数拍子。
哲学彩蛋（括号里是出处 `4_Eidolon/_设计/哲学.md`）：
- 两个切点铺满全曲（§2 用户的耳朵是校准器）
- 锚点 + 规则（§1）
- 特效服务于故事（§11）
- 情绪是心海上的一艘船（§16）
- 涨潮泡开核桃（§14 格罗滕迪克）
- 宫殿一间一间搭（今天的整理）

Suno 的 Style 栏不变：
```
Electro-pop, bright synth stabs, bouncy bass and handclaps; layered synth chorus, crisp polished production; upbeat 122 BPM bounce; playful female talk-sing in rhythmic half-spoken verses, high light upper-register sung chant chorus with call-and-response backing voices.
```

## 改了什么
- Verse 1 整段换成「人 + AI 做片子」：两个音铺满全曲；AI 听不见却数拍子；「太吵 / 再开心点」= 人只给一句话的决定。
- Verse 2 后半换成哲学：特效不为炫技、情绪是心海上的船。
- Bridge 加「别敲核桃，让潮水涨上来」（格罗滕迪克）。
- Outro「New day」→「You and me」。
- 副歌和 Pre 一个字没动（已经证明 Suno 唱得好）。

## 分镜要跟着改的地方（等你定词后再改）
- Verse 1 的小场景换成：她哼两个音符 → Save 用积木铺出一整条路；Save 戴着耳机但耳机是空的，它掰着手指数拍子；她说「太吵」，Save 把一个大喇叭塞进抽屉。
- Verse 2 后半：一个想放烟花的按钮被 Save 轻轻按住，烟花只在讲故事的地方绽开一朵；一艘小纸船在她脑袋里的海上摇。
- Bridge：一颗大核桃泡在慢慢涨起来的水里，自己裂开，里面是光。
