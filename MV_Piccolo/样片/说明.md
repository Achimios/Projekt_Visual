# Piccolo 样片说明（按版本追加，不覆盖）

## 01_纸卷_接通_0-30_v1（2026-10-24，Fable）
- 范围 0:00–0:30。全部代码画的（`4_Eidolon/tools/mv_piccolo/roll.py`），纯 PIL，CPU，1080p 24 fps，一帧 ≈ 0.1 s。
- 数据：`分析_纸卷.json`（`analyze.py`）—— 拍点来自 ReadScreen 的 `感官.json`（115.28 BPM），洞 = 12 个 mel 频带的起音峰（能量门控），旋律 = Demucs other 轨的 pyin（120–2500 Hz；这首 intro 主旋律基频 ≈ 170 Hz）。
- 画面里每样东西说的都是真话：洞的位置 / 长度 = 真实音事件；读头走速 = 真 BPM；拐杖 = 阻尼单摆被低频起音踢；小鸟高度 = 旋律 f0；底噪墨点密度 = 高频爆裂声。左下角标签是真参数。
- 只判：构图、画面感、情绪、节奏。不判形象细节（头 / 帽子还糊）。
- 已知待改：头和帽子读不清；小鸟偏小；洞飞向他的路径还是直线弹簧（想要带一点弧）；0:28 拐杖「落地第一下」还没做成一个事件。

## 02_纸卷2D_接通_0-30_v2（2026-10-24，Fable）—— 👤「piccolo 走 2D 风格」后的重做
- v1 被 Leo 判为 shit（平光图表、无情绪）。v2 换成 _参考库 的 2D motion design 语法（`roll2d.py`）：黑底 + 看不见的网格（g = H/18）、白 / 灰几何、极小等宽真数据、虚线贝塞尔弧 + 中点箭头、生长代替淡入、两段式先快后慢（τ 3 帧 / 9 帧）、一个强调色（红）、大字 + 极小字没有中间尺度。
- 故事同 Thymos：0–8 s 只有一条旋律线和它的 [t, Hz] 面包屑（机器未通电，读头是灰的）；8.0 s 机器接通 —— 12 行频带从左长出来、大字 115.28 拼出再对数缩回；每个被读到的起音填实成红 1 帧；他由 17 笔模块笔画组装，每一笔的出生 = 一个真实起音（虚线弧从那个洞飞到笔画，带 b / Hz / s / t 标签，1.2 s 衰减）；拐杖在最后一笔之后出现、在第一句人声 28.40 s 落地（红印）。
- 想表达的情绪：**被机器接通的老派体面** —— 空 → 通电（一个事件）→ 一笔一笔被拼出来 → 站稳、拐杖点地，刚好在他开口的那一刻。
- 只判：构图、画面感、情绪、节奏。已知待改：他的字形还偏机器人（笔画等宽、无姿态变化）；8–28 s 之间除了拼人没有第二件事；相机漂移幅度要在播放器里验。

## 03_网格vs摆_0-30_v3（2026-10-24，Fable）—— ReadScreen 第 1 轮审核 + 分镜硬要求后
- 分镜真源：`__synapsis/剪辑/00 开头 0-30`（10 个镜头，S06 按 ReadScreen 意见拆成 S06 / S06b）。渲染器 `roll3.py`：每镜独立变焦 / 世界中心 / 转角（硬切 = 参数不连续），镜内永远在动；黑帧休止 28.32–28.40。
- v2 → v3：卷帘和他合成一个空间（他站在纸卷上，洞从身体穿过，笔画带黑镂空）；拍线以 115.28 BPM 刷过（bar 1 = 贝斯进入 8.434）；每个洞相对最近八分格的偏移 = 红刻度（越偏越亮）；读头标签实时 swing 比率；他在反拍（按真 swing 落点）bob；contrapposto + 歪帽檐 + 笔画粗细变化；每 4 小节 + S05→S06 清屏重长；S03→S04 切前推近（溶解是切的前奏）；S07 世界转 90°（唯一一次空间翻转）；S09 杖尖特写 + swing 大字。
- ⚠️真话：实测 swing ≈ 0.48（反拍落点中位数，直拍 = 0.50）—— 这首歌的采样被机器量化得很直，摆主要在人声和旋律里。所以画面里红偏移刻度稀、读数接近 0.5，这本身就是 Thymos 的「被对齐成格子」。
- 机器检查：720 帧里除 0.0 s 黑场和 28.32–28.40 黑帧休止外，没有相邻帧差为 0 的帧（相机永不静止）；清屏填白出现在 8.43 / 16.77 / 18.86 / 25.12。
